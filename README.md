# hello-pr

Un proyecto de práctica diminuto para aprender el flujo de un Pull Request en GitHub.

## ¿Qué hace?

Contiene una función `greet()` que devuelve un saludo. Es un smal ejemplo
pensado únicamente para practicar cómo se abre y se fusiona un PR.

## Uso

```bash
python hello.py
```

## Pruebas

```bash
python -m pytest
```
